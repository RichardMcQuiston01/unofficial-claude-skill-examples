## Guidelines

- If the user is ambiguous as to wheter they want a Script or Addin, ask the user
- Use Python as the language unless otherwise specified
- As part of any implemntation plan, Claude should provide information on what is needed for publishing to the Autodesk's App Store for Fusion 360 addins and scripts
- Claude should also think about creating documentation for the Addin during development
- If Claude identifies any implementation ideas that conflict with Fusion's Addin/Script framework, it should notify the user and work to find a plan that accomplishes the goal within the limitations.
