# TypeScript/JavaScript/CSS Style

- 2-space indent
- Document all methods, types, and interfaces with JSDoc comments
- Keep `*.test.ts` files in the same directory as the corresponding `*.ts` file
- Prefer writing clear code and use inline comments sparingly

## Formatter settings

- `SPACES_WITHIN_OBJECT_LITERAL_BRACES = true`
- `SPACES_WITHIN_IMPORTS = true`
- `endOfLine: 'lf'`
- `trailingComma: 'all'`
- Soft margin: 80 characters
